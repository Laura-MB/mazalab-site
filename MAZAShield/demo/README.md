## Quick Start

Desde la raíz del repositorio, con dependencias ya instaladas (`npm install`):

```powershell
.\demo\start-demo.ps1
```

El script comprueba `/health`, arranca `npm run dev` en una ventana aparte si hace falta y abre el dashboard en el navegador (por defecto `http://localhost:3010/demo/gaming-dashboard.html`; el puerto sale de `.env` o 3010).

### Opciones útiles

```powershell
.\demo\start-demo.ps1 -WithPresentation
.\demo\start-demo.ps1 -NoBrowser
```

También puedes usar `demo\start-demo.cmd` desde el Explorador de archivos (sin cambiar ExecutionPolicy).
