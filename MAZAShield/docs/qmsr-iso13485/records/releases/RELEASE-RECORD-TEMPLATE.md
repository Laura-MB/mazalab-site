# Release Record (template) – MAZALab Mother Brain

**Uso:** completar al etiquetar un *release* (semver) o al cerrar *Management Review* con evidencia *build*.

| Campo | Valor |
|--------|--------|
| **ID / título** | e.g. `RR-2026-05-20-v0.1.x` |
| **Fecha** | YYYY-MM-DD |
| **Tag Git** | `v*` |
| **Commit SHA** | *full* *hash* |
| **Node.js** | salida `node -v` |
| **npm** | salida `npm -v` |
| **OQ / validación** | enlace a [OQ-2026-Q2-Light.md](../validation/oq/OQ-2026-Q2-Light.md) o sucesor |
| **SOUP** | [soup-register-v1.md](../soup-register-v1.md) versión o nota *delta* *lock* |
| **RVTM** | [rvtm-light-v1.md](../rvtm/rvtm-light-v1.md) *snapshot* o *PR* *ref* |
| **Resultado CI** | *URL* o *PASS* *local* *recorded* *by* *name* |
| **Notas / NC** | texto libre breve |
| **Aprobado por** | CPA / Eng / QA (*TBD*) |
